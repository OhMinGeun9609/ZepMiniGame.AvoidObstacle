
Zep메타버스만들기

구성
1. 메타버스 화면
   메타버스 화면은 강의를 참고하여 타일맵을 활용해 제작.
   스프라이트는 강의에서 제공받은 에셋 활용
   NPC캐릭터의 근처에 다가가면 해당 NPC의 좌표 위에 E키를 누르라는 메세지가 뜨도록 설정
   가까이 다가가 E키를 누르면 미니게임 타이틀 화면으로 이동함
   
2. 미니게임 타이틀
   미니게임을 시작하기 전, 게임설명이 명시되어 있고, 버튼을 누르면 미니게임을 시작할지,
   메타버스 화면으로 다시 돌아갈지 선택할 수 있는 버튼 2개 구현
   게임설명 UI는 판넬과 텍스트 레거시 UI를 활용
   폰트는 초기 지급되었던 강의에서 제공받은 폰트 활용
   
3. 미니게임 화면
   강의 중 만든 게임 "FlappyPlane"을 확장해 제작.
   타이틀 화면에서 게임시작 버튼을 누르면 진입.
   이동은 상하이동만 가능하며, 좌우이동 불가
   목표는 장애물을 피해서 스테이지를 클리어 하는
   것.

   조작은 W,s 또는 위, 아래 방향키로 조작가능

   총 스테이지는 3개, 스테이지 2부터 피해야 하는 장애물
   종류가 하나씩 추가됨.

   게임 종료후 PlayerPrefs를 이용하여 최고 기록 측정
   후 최고기록과 현재기록을 동시에 출력함

   버튼 3개가 출력되고, 각각 재도전, 타이틀 화면 복귀, 메타버스화면 복귀
   기능이 있음.
